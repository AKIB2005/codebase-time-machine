any new task-related side effects.

## 6. Known Historical Issues and Caveats

These caveats are established from repository evidence and should be understood
before modifying the codebase.

### 6.1 SQLite Repositories Are Not Connected to TaskService

**Evidence:** `c8491ae` adds `TaskRepository` and `UserRepository`. Zero subsequent
commits modify `TaskService` to use them. `TaskService` uses `self._store: dict[int, Task]`
throughout the entire history.

**Effect:** All task data is **lost on every server restart**. The SQLite
infrastructure exists and the schema is initialised at startup via
`initialize_db()`, but the service layer does not use it.

**Unknown:** Whether this is a planned but incomplete migration or deliberate staging.

---

### 6.2 The Pagination Bug Was Committed Before Being Fixed

**Evidence:** Commit `861190a` includes a `# BUG:` comment within the committed
code identifying the defect. Commit `a4544f2` corrects it.

**Current state:** The fix is in place. The test in `test_task_service.py`
(`test_pagination_page1`) verifies the corrected behaviour.

---

### 6.3 Test Coverage Gaps

**Evidence:** `af36d82` adds tests for `Task`, `TaskService`, `AuthService`,
and `EventBus`. The following are not covered:

- `taskflow/api/tasks.py` (REST endpoints)
- `taskflow/api/auth.py` (registration/login/logout)
- `taskflow/api/auth_middleware.py` (require_token)
- `taskflow/models/task_repository.py`
- `taskflow/models/user_repository.py`
- `taskflow/db.py`
- `taskflow/security/rate_limiter.py`

No CI configuration exists in the repository.

---

### 6.4 In-Memory Rate Limiter Does Not Survive Restarts

**Evidence:** `taskflow/security/rate_limiter.py` uses `time.monotonic()`
and a plain Python dict for failure tracking. No persistence, no shared
state across processes. No code comment in the repository acknowledges
this limitation.

---

### 6.5 Admin Role With No Admin Endpoints

**Evidence:** `User.role` field supports `'admin'|'member'` (added `967b11a`).
`AuthService.require_admin()` exists. No endpoint in `taskflow/api/` calls
`require_admin()` in any commit in the repository.

---

### 6.6 No API Documentation

**Evidence:** No OpenAPI/Swagger spec, no API reference document, and no
consumer code exists in the repository. The available interface can be
inferred from the Blueprint routes in `taskflow/api/tasks.py` and
`taskflow/api/auth.py`, but no formal specification is provided.
